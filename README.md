# bosch-devops-challenge
Node.js visit counter application with Redis, Docker and CI/CD

# Bosch DevOps Challenge

[![Build and Test](https://github.com/radivojevickristina/bosch-devops-challenge/actions/workflows/ci.yml/badge.svg)](https://github.com/radivojevickristina/bosch-devops-challenge/actions/workflows/ci.yml)

A simple Node.js application that uses Redis to track visits. The project is containerized with Docker and Docker Compose and includes a Bash healthcheck script and a GitHub Actions CI pipeline for automated linting, testing, and Docker builds.
